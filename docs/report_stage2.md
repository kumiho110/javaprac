Этап 2. Разработка связывающего кода с помощью Hibernate

В рамках второго этапа реализованы следующие части проекта: разработаны классы хранимых объектов для отображения таблиц базы данных на Java-объекты; настроено отображение БД на объекты с помощью Hibernate/JPA; разработаны служебные классы доступа к данным (DAO), реализующие типовые запросы приложения к базе данных; разработаны модульные тесты на TestNG для методов DAO-классов и нетривиальной логики хранимых объектов; дополнен Ant build-файл, в который добавлены задачи сборки проекта, сборки тестов и выполнения тестов.

Тесты проверяют основные CRUD-операции DAO-классов, типовые запросы к базе данных и сценарии, в которых метод находит запись или не находит запись, возвращает непустой или пустой список, а также различные ветви поведения методов, если они зависят от входных параметров.

Нетривиальная логика хранимых объектов проверяется косвенно через DAO-методы.

Во всех тестах с помощью assert проверяются свойства результата, которые можно проверить в соответствующей ситуации: значения полей объектов, связанные сущности, статусы, даты создания/обновления, значения по умолчанию, корректность фильтрации и поиска.

Структура реализованной части:
src/main/java/.../model — классы хранимых объектов;
src/main/java/.../dao — DAO-классы;
src/test/java/.../dao — TestNG-тесты;
src/test/resources — тестовая конфигурация Hibernate/JPA;
build.xml — Ant-задачи для работы с БД, сборки и запуска тестов;
build.gradle.kts — Gradle-конфигурация зависимостей и запуска тестов/coverage.

Для запуска тестов требуется установленный JDK 21, Apache Ant и PostgreSQыL.
Должна быть подключена база данных с параметрами:
db.host=localhost;
db.port=5432;
db.name=javaprac;
db.user=postgres;
db.password=0438.

Или можно запустить БД через докер.
В корне проекта: 
docker compose up -d

Запуск тестов через Ant:
ant test.

Перед запуском Ant подготавливает пустую БД для тестов (db-clean + db-create), затем запускает тесты через Gradle.

Запуск тестов с построением отчёта покрытия через Ant:
ant test-report.

Запуск тестов через Gradle:
./gradlew clean test.

Запуск тестов с отчётом покрытия JaCoCo через Gradle:
./gradlew clean test jacocoTestReport.

HTML-отчёт JaCoCo находится по пути:
build/reports/jacoco/test/html/index.html.
